# MusicBridge

Reproductor y control remoto web sin cuentas. Usa sesiones HTTPS temporales para conectar dos dispositivos con un QR. Consulta la [guía de emparejamiento](docs/PAIRING.md) para ver la configuración. Proyecto independiente de La-vuelta.

La búsqueda de YouTube usa `YOUTUBE_DATA_API_KEY` en el servidor. Para probarla en local, define la variable en el entorno del proceso antes de ejecutar `npm run dev`.
